## 1. Bugs — still open, need a code fix before public free-tier use

### B-1 [Medium] Live fetch partial publish — half-empty catalog still publishes

- **Evidence:** `crates/catalog/src/main.rs:106-115` + `crates/catalog/src/fetch.rs:59` +
  `crates/catalog/src/artifact.rs:40-48`. `fetch_openrouter` skips failed
  per-model endpoint fetches with a count; `artifact::publish` runs after the DB
  write with no skipped-ratio gate.
- **Repro:** mock OpenRouter returning 50% 404 on `GET /v1/models/{id}/endpoints`
  → `catalog-sync --fetch-openrouter` publishes a catalog missing half its
  offerings; `FETCH_OPENROUTER=1` in compose then makes every host serve it.
- **Fix:** gate publish on `skipped / total < THRESHOLD` (e.g. 5%, env-overridable).
  Above threshold → abort publish, keep last good artifact, non-zero exit so the
  sync container / CI step surfaces the failure. Add a `fetch_skipped_total`
  log/counter. Needs a test: mock 50% 404 → no new manifest published.
- **Source:** `docs/review-2026-10-31.md` §3 B-1; coverage gap §8.

### B-2 [Medium] `free_offers` wall-clock / artifact-time skew

- **Evidence:** Iter 11 F11 introduced `valid_until_unix` on `free_offers` /
  promos, wall-clock-checked at request time. Clock drift between the
  catalog-sync container and the gateway (or a stale ranking doc) can keep
  expired promos live or evict active ones early.
- **Fix:** include `generated_at` in the ranking document; gateway rejects (or
  downgrades) docs older than `RELOAD_INTERVAL_SECS * 2 + SKEW` (e.g. 5 min
  skew budget). Add a staleness metric/counter; log at publish the
  `valid_until_unix - generated_at` delta for short windows.
- **Source:** `docs/review-2026-10-31.md` §3 B-2 and §7 P1 #6; `docs/review/PennyRouter-full-review-2026-10-31.md` §1 B5.

### B-3 [Medium] Empty catalog still advertises the 6-model virtual menu

- **Evidence:** `crates/gateway/src/lib.rs` curated `GET /v1/models` returns the
  six `openrouter/pair/*` ids unconditionally; virtual chat routing fails closed
  (503 `no_eligible_offering`) when no snapshot is loaded. Triggers: fresh prod
  volume with no artifact, `RELOAD_INTERVAL_SECS=0` with first-load failure,
  corrupt artifact on boot.
- **Repro:** boot gateway with `CATALOG_DB=/catalog` pointing at an empty
  directory → `GET /v1/models` 200 with 6 entries, `POST /v1/chat/completions`
  with any virtual id 503. Client that caches the menu retries forever.
- **Fix:** gate `GET /v1/models` on catalog readiness — 503 with `Retry-After`
  until first snapshot loads — and/or expose readiness separately (see I4).
  At minimum, make empty-catalog health distinct from healthy (I4); document
  the `RELOAD=0` semantics.
- **Source:** `docs/review/PennyRouter-full-review-2026-10-31.md` §1 B1/B4; related
  `docs/review-2026-10-31.md` §6 `CATALOG_DB` prod-wiring gap.

### B-4 [Low] `route_pinned` empty model remainder

- **Evidence:** `crates/gateway/src/routing.rs:route_pinned` strips `modal/` or
  `baseten/` and forwards the remainder verbatim. `model: "modal/"` or
  `"baseten/"` yields `""` forwarded to `POST /v1/chat/completions`.
- **Fix:** 400 early with `model_not_provided` (or equivalent OpenAI-shaped
  error) when the remainder is empty; add a `tests/providers.rs` case for
  zero-length remainder.
- **Source:** `docs/review/PennyRouter-full-review-2026-10-31.md` §1 B2.

### B-5 [Low] Stream path has no absolute total cap

- **Evidence:** `crates/gateway/src/lib.rs:52-53`, `read_capped_upstream` 16 MiB
  bound is buffered-only; streaming path is per-chunk unbounded with
  `idle=60s` per chunk + `total=300s` not enforced on streams. A slow trickle
  (1 byte/59s) can hold an `upstream_slots` semaphore slot indefinitely; a
  1 GiB slow stream never hits the 16 MiB cap.
- **Fix:** enforce an aggregate stream total (bytes and/or wall duration) on the
  streaming path; on breach, emit a terminal SSE `error` event and close with
  500/`stream_too_large`. `UPSTREAM_MAX_CONCURRENT=64 / QUEUED=128` already
  bounds fan-out; this caps single-stream hold.
- **Source:** `docs/review-2026-10-31.md` §3 B-4; `docs/review/PennyRouter-full-review-2026-10-31.md` §1 B6.

### B-6 [Low] Query variation fragments the session table

- **Evidence:** session key is seeded hash of `(authorization, model)`; fallback
  logs already redact query values (Iter 11), but chat `POST` query variation
  still creates distinct session entries evicted only after `SESSION_TTL=30m`.
- **Fix:** normalize/strip query from the session key.
- **Source:** `docs/review-2026-10-31.md` §3 B-3.

### B-7 [Low] `privacy/` ZDR injection vs budget precedence

- **Evidence:** `provider.max_price` fail-closed (Iter 14, 400 `budget_exceeded`)
  can fire even though a cheaper provider would satisfy a `privacy/` retry.
- **Fix:** document precedence `budget > affinity > privacy` (no code change
  unless the product decision is to retry before failing closed).
- **Source:** `docs/review-2026-10-31.md` §3 B-5.

## 2. Security — still open

### S-1 [Medium] Debug UIs unauthenticated

- **Evidence:** `GATEWAY_UI=1` (`GET /ui`) + `catalog-ui` binary are localhost-bind
  but can be exposed via Caddy/compose without auth in prod.
- **Fix:** gate behind admin token / mTLS or ensure Caddy never proxies `/ui`
  externally; document the prod expectation. `compose.prod.yaml` already omits
  `GATEWAY_UI`; keep it that way and add a comment citing this finding.
- **Source:** `docs/review-2026-10-31.md` §4 S-1.

### S-2 [Low] Authorization forwarding to pinned upstreams

- **Evidence:** Iter 16 forwards `Authorization` unchanged to Modal/Baseten by
  design. A mis-routed OpenRouter key could leak to a foreign upstream.
- **Fix:** doc warning; optional key-prefix check (`sk-or-*` vs `sk-*`).
- **Source:** `docs/review-2026-10-31.md` §4 S-2.

### S-3 [Info] `OPENROUTER_BASE_URL` / `CATALOG_DB` operator-only surfaces

- **Evidence:** env-var controlled, not request-controlled; not exploitable via
  the gateway path. Included for completeness; consider URL allowlist if
  hardening further.
- **Source:** `docs/review-2026-10-31.md` §4 S-3.

## 3. Observability / operability — still open

### I4 [Medium] No `catalog_ready` signal; `/health` lies when empty

- **Evidence:** `GET /health` returns `{"status":"ok"}` even with an empty
  catalog. Deployments health-check only `/health`, so the Terraform `cloud-init`
  readiness loop (previously fixed in F09) can still report green while the
  gateway is functionally down for virtual models (B-3).
- **Fix:** add `GET /ready` (or `catalog_ready` field on `/health` / `/metrics`);
  wire deploys' health checks to it. This also closes B-3's user-visible symptom.
- **Source:** `docs/review/PennyRouter-full-review-2026-10-31.md` §1 B1/B4 + §2 I4;
  `docs/review-2026-10-31.md` §7 P1 #5.

### P0 — Load p99 tail still unconfirmed

- **Evidence:** `tests/load/results/compare-20261029T212247Z` (Iter 12 re-run,
  20 sessions × 15s, 20ms mock, 1 CPU/1 GB): json p50 +0.26ms identical to Iter 3,
  but p99 +13.10ms vs Iter 3 +0.40ms — single run, variance unconfirmed.
- **Fix:** re-run N=5, report median p50/p99; close or file the regression.
  The reviewers recommend a `make load-baseline` target that loops
  `tests/load/compare.sh` three times and reports medians, gated in the PR
  template for any `crates/gateway` change.
- **Source:** `docs/review-2026-10-31.md` §5 and §7 P0 #2; `docs/review/PennyRouter-full-review-2026-10-31.md` §2 I3.

### I5–I7 Hygiene

- **I5:** Pin `Cargo.toml` crate versions more tightly; add `cargo audit` in CI;
  keep `reqwest` as `default-features = false + rustls-tls` with a comment citing
  F03 so `gzip` is not re-enabled (lockfile currently carries pre-F03 minors).
- **I6:** `price.rs` promo matching is O(models × promos) at rebuild — at
  Iter 18 live scale (456 models × 1483 endpoints) a `HashMap<(model_id, provider, Option<tag>), promo>` per sync cycle is cleaner.
- **I7:** `CATALOG_DB` (directory/manifest/file tri-state) vs `CATALOG_IMAGE` vs
  `SYNC_INTERVAL` vs `RELOAD_INTERVAL_SECS` naming — add one "Configuration"
  table (var, default, units, hot-reloadable?) to `docs/operations.md` +
  `.env.example`.
- **Source:** `docs/review/PennyRouter-full-review-2026-10-31.md` §2 I5–I7.

## 4. Docs / DX still open

- `docs/routing.md` still frames routing as suffix filters on OpenRouter models
  (pre-Iter-13 mental model). Should open with the 6 virtual ids as the primary
  contract; move suffix history to an appendix (full review I1).
- `README.md` / `docs/README.md` still imply arbitrary model ids are first-class
  routed inputs, eliding that virtual ids are the policy path and raw ids are
  unprotected passthrough / `quality_floor` bypass (full review I2).
- `docs/operations.md` / `.env.example` do not call out that `RELOAD_INTERVAL_SECS=0`
  opts into "never recovers from first-load failure" (full review B4).
- `compose.yaml` `extra_hosts: host.docker.internal:host-gateway` is gated on
  `OPENROUTER_BASE_URL`, not `OLLAMA_BASE_URL` (which does not exist) — rename or
  alias to `UPSTREAM_BASE_URL` or document the Ollama tweak (full review B8).
- `crates/gateway/src/metrics.rs` log-writer vs `cargo test --nocapture` stdout
  interleaving deserves a comment so future test writers do not chase phantom
  output (full review B7).
- `CRATE_CC_NO_DEFAULTS` / build.rs `GIT_HASH=unknown` fallback untested
  (top-level review §8 coverage gap).
