## 2. Architecture Overview

```
Client --(BYOK Authorization)--> Gateway (Axum, crates/gateway/src/lib.rs:1-1407)
  | health / metrics / ui (GATEWAY_UI=1) / fallback proxy / chat+responses+models
  +-- routing::Router <-- Snapshot { models: HashMap<String,Vec<Offering>> }
  |     ^ periodic reload (RELOAD_INTERVAL_SECS=60) via CATALOG_DB
  +-- Metrics (metrics.rs:342) histograms, pennyrouter_* counters, Throttled tracking (60s cooldown)
  +--> Upstream: OpenRouter (OPENROUTER_BASE_URL default https://openrouter.ai/api)
       + pinned: MODAL_BASE_URL / BASETEN_BASE_URL (Iter 16)
       Semaphores: UPSTREAM_MAX_CONCURRENT=64, UPSTREAM_MAX_QUEUED=128

Offline: catalog-sync (crates/catalog, ~3000 LOC)
  fetch.rs -- models + per-model endpoints (live or fixtures) -> run_fixture_sync boundary
  process.rs/rank.rs/price.rs/schema.rs/store.rs (rusqlite) -> quality_tier/score, effective_cost
  judge_catalog.rs + judge_{openai,baseten,modal} -> audit trail
  artifact.rs/sync.rs -> versioned DB + manifest + ranking doc
  main.rs -- --fetch-openrouter, --judge[-backend], --sample-rate/caps
Catalog-ui (crates/catalog-ui) localhost browser, Docker.
Deploy: compose.dev/prod/perf + Hetzner CCX13 Terraform + Caddy TLS.
```

Data-plane invariant preserved: realtime path is one HashMap lookup + in-snapshot sort (no DB/network). Control plane (sync/rank/judge) is fully offline.

## 3. Bugs — with file:line refs, severity, repro

*Prior F01–F11 referenced to Iter 11 landed notes; re-checked source confirms fixes present. New findings below.*

**B-1 [Medium] Live fetch partial publish risk** — `crates/catalog/src/main.rs:106-115` expects both `models_path`/`endpoints_dir` when `FETCH_OPENROUTER=1`; `fetch.rs:59` skips failed per-model endpoints with count, but `artifact.rs:40-48` publishes manifest after DB write — a run with many skipped endpoints (e.g. 404s) still publishes a catalog missing offerings, with no skipped-ratio gate. *Repro:* mock OpenRouter returning 50% 404 on endpoints → catalog publishes with half data. *Fix:* gate publish on `skipped / total < threshold` (e.g. 5%).

**B-2 [Medium] `free_offers` wall-clock vs artifact-time skew** — promo/free filtering uses `valid_until_unix` wall-clock-checked (Iter 11 F11 fix). Container clock drift or stale ranking doc can keep expired promos live or evict active ones early. *Fix:* include `generated_at` in ranking doc and reject docs older than `RELOAD_INTERVAL*2 + skew`.

**B-3 [Low] Query string vs session key** — fallback logs redact query values (Iter 11), correct. Session key is `(authorization, model)` hash — query variation on chat POST creates duplicate sessions evicted only after 30m TTL. *Fix:* normalize/strip query from session key.

**B-4 [Low] `MAX_UPSTREAM_BYTES=16MiB` on buffered bodies only** — streaming is per-chunk unbounded; slow-loris (1 byte / 59s) can hold `upstream_slots` for `idle=60s` indefinitely despite 300s total cap not enforced on streams. *Fix:* enforce absolute stream total on streaming path.

**B-5 [Low] Virtual `privacy/` ZDR injection vs budget** — `provider.max_price` fail-closed (Iter 14) can 400 even though privacy retry would succeed on cheaper provider. Document precedence: budget > affinity > privacy.

**B-6 [Low] Catalog init idempotency race** — presence-based migration for `judge_model` may race concurrent sync+gateway reader on same DB file. Mitigated by manifest discovery; recommend deprecating direct `CATALOG_DB` in favor of directory mode.

**B-7 [Info] Throttle cool-down 60s global per provider** — 429 on `openrouter/free` throttles provider for all tiers. Intentional v1 (organic 429 history only). Acceptable.

## 4. Security

No new High/Critical. Iter 11 keys separation holds.

**S-1 [Medium] Debug UIs unauthenticated** — `GATEWAY_UI=1` and `catalog-ui` on localhost bind, but operator must ensure not exposed via Caddy without auth. Gate behind mTLS or admin token in prod.

**S-2 [Low] Authorization forwarding to pinned upstreams** — Iter 16 forwards `Authorization` unchanged to Modal/Baseten by design; mis-routed OpenRouter key could leak. Doc warning + optional prefix check (`sk-or-*` vs `sk-*`).

**S-3 [Low] `OPENROUTER_BASE_URL` SSRF surface** — operator-controlled env var only, not request-controlled. Not exploitable via gateway path. URL allowlist if hardening.

**S-4 [Info] No `unwrap`/`expect` in gateway hot path** — clean; only spawn + tests.
